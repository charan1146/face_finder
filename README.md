# AI Face Recognition System

This project is a real-time AI Face Recognition application developed using Python, OpenCV, and DeepFace.

The application uses a webcam to detect and recognize faces by comparing live webcam frames with a stored reference image.

## Features

- Real-time webcam face recognition
- AI-powered face verification
- Detects and compares human faces
- Displays recognized person name
- Beginner-friendly deep learning project

## Technologies Used

- Python
- OpenCV
- DeepFace
- TensorFlow

## AI Concepts Used

This project demonstrates:

- Computer Vision
- Face Recognition
- Deep Learning
- Facial Verification
- Real-Time AI Processing
- Image Comparison
